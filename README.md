## Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/Linxvicky2049/CODIVA-intern-tasks.git
```

### 2. Navigate into the project

```bash
cd CODIVA-intern-tasks
```

### 3. Create a virtual environment

```bash
python -m venv env
```

### 4. Activate the environment

**Windows PowerShell:**

```powershell
.\env\Scripts\Activate.ps1
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Run a project

For example:

```bash
python "Level-3/Task-2-Neural-Network/src/neural_network.py"
```

Run each task from the repository root so its relative dataset and output paths resolve correctly.
