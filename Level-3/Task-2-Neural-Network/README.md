# Neural Network Classification

## Codveda Technologies Machine Learning Internship

**Level:** Level 3  
**Task:** Neural Network Classification  
**Model:** Multi-Layer Perceptron (MLP)  
**Status:** Completed  
**Programming Language:** Python

## 1. Project Overview

This project implements an Artificial Neural Network using Scikit-learn's Multi-Layer Perceptron Classifier (MLPClassifier).

The model uses the Codveda-provided customer churn dataset to predict whether a customer is likely to discontinue a service.

The project demonstrates neural network development, data preprocessing, hyperparameter tuning, model evaluation, and training loss visualization.

## 2. Dataset

The project uses the provided Churn Prediction dataset.

- Training dataset: `churn-bigml-80.csv`
- Testing dataset: `churn-bigml-20.csv`
- Training records: 2,666
- Testing records: 667
- Input features: 19
- Target variable: `Churn`

## 4. Methodology

### Data Preparation
- Loaded the training and testing datasets.
- Checked missing values and duplicate records.
- Removed duplicate records.
- Separated input features from the target variable.
- Identified numerical and categorical features.

### Data Preprocessing
- Applied median imputation to numerical features.
- Applied standard scaling to numerical features.
- Applied most-frequent imputation to categorical features.
- Used One-Hot Encoding for categorical variables.
- Implemented preprocessing with ColumnTransformer and Pipeline.

### Neural Network Development
- Implemented an MLPClassifier.
- Used ReLU and tanh activation functions as candidate configurations.
- Tested different hidden-layer architectures.
- Applied regularization using the alpha parameter.
- Enabled early stopping to help control overfitting.
- Used GridSearchCV and five-fold Stratified Cross-Validation.

### Model Evaluation
The trained model was evaluated using:
- Accuracy
- Precision
- Recall
- F1 Score
- ROC-AUC
- Classification Report
- Confusion Matrix
